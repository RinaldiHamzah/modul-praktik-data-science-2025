Praktikum Data Science ini bertujuan untuk memahami dan menerapkan proses analisis data teks (text mining) menggunakan pendekatan machine learning. Studi kasus yang digunakan adalah analisis sentimen teks berbahasa Indonesia dengan tiga kelas sentimen, yaitu negatif, netral, dan positif.

Proses praktikum meliputi tahapan preprocessing data, exploratory data analysis (EDA), ekstraksi fitur, pembangunan model klasifikasi, serta evaluasi dan perbaikan kinerja model.
